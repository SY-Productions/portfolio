### Transparency Values for UI Effects:
- 10% opacity: Element background - e.g., `from-[#7B2CBF]/10`
- 20% opacity: Hover state background - e.g., `from-[#7B2CBF]/20`
- 30% opacity: Active state background - e.g., `from-[#7B2CBF]/30`
- 50% opacity: Borders and lines - e.g., `border-[#9D4EDD]/50`
- 80-90% opacity: Text and icons - e.g., `text-[#9D4EDD]/90`

### Gradient Combinations:
- Main gradient: `bg-gradient-to-r from-[#7B2CBF] to-[#9D4EDD]`
- Dark gradient: `bg-gradient-to-r from-[#5A189A] to-[#7B2CBF]`
- Full spectrum: `bg-gradient-to-r from-[#5A189A] via-[#7B2CBF] to-[#9D4EDD]`

### Shadow Effects:
- Regular shadow: `shadow-[0_5px_15px_rgba(123,44,191,0.2)]`
- Glow effect: `shadow-[0_0_15px_rgba(157,78,221,0.3)]`
